## ⚡ Tính Năng Nổi Bật

1. **Hỗ trợ Remote TV Sharp**: Bắt trọn vẹn phím tua nhanh vật lý `>>` và tua lùi `<<` (tăng tốc 30s $\rightarrow$ 1p $\rightarrow$ 2p $\rightarrow$ 5p/nhịp).
2. **5 Nguồn Phim Đa Dạng**: Tự động tổng hợp từ KKPhim, OPhim, NguonC, CoBePhim (chuyên cổ trang kiếm hiệp xưa) và Torrent 4K Ultra HD kèm phụ đề tiếng Việt tự động.
3. **Cơ Chế Remote Config Siêu Đơn Giản**: Chỉ cần sửa 1 file duy nhất [`config/sources.json`](./config/sources.json) khi nguồn phim đổi tên miền, hệ thống sẽ tự động build lại app ngay lập tức!
4. **Hệ Thống Tự Hành (Daily Health Check)**: Quét kiểm tra kết nối các nguồn phim định kỳ 07:00 sáng mỗi ngày, tự động báo động nếu phát hiện nguồn chết.
